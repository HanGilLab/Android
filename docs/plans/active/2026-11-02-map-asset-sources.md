# 온라인 지도 스타일, 글꼴과 아이콘 출처 확인

- 상태: 출처 문서와 로컬 검증 완료, 최신 PR 및 실제 표시 추적 중
- 요구사항: 출품 체크리스트 DES-08, 기존 지도 사용 조건 기록의 구체적인 누락 보완

## 목표와 범위

현재 main의 DemoMap은 라이트 Liberty와 다크 Dark를 사용하고 CoursePreviewLayers는 Noto Sans Regular를 요구하지만 docs/maps.md는 Liberty와 렌더러 고지만 기록한다. 실제 공식 style JSON의 glyphs/sprite/fontstack, 공개 제작 원본과 사용 조건을 대조해 원격 서비스와 앱에 직접 포함한 에셋을 구분한다. 이름만으로 글꼴이나 아이콘의 라이선스 및 실제 제공 버전을 추정하지 않는다.

PR74 위치 임시 저장, PR75 마침 복습, 잠금 해제, AVD/권한/DB와 기술 의존성이 없는 문서 범위다. 두 기존 작업과 미커밋 계획을 보존한다. 실제 도로 좌표, 내비 목적지와 복습지도는 범위 밖이다. DES-08 전체와 release 의존성 전체 고지 완료는 별도로 남긴다.

## 구현 단계

1. 현재 앱과 기존 지도/브랜드/출처 문서, 체크리스트 및 PR 상태를 확인한다.
2. 두 공식 style endpoint와 서비스/공개 upstream 원문을 읽고 정제 자료를 만든다.
3. 확인한 출처/조건, 바이트 대조의 한계와 미확정된 served 버전을 구분한다.
4. 검증과 리뷰를 마친 뒤 PR로 반영한다.

## 변경 전후 측정

기준 main은 dd4897880b24776c1599bb18096abc5bcc0a2219이다. 렌더러, style/fontstack, 네트워크/수명주기, 사용자 화면과 SDK 실행 코드를 바꾸지 않는 출처 문서 보완이다. 앱 실행 성능과 사용 흐름이 바뀌지 않으므로 앱 성능 전후 측정 적용 제외다. 원격 JSON hash와 대조 건수, 회귀 검사 개수는 성능 개선 수치가 아니다. 새 성능 원값과 개선율을 만들지 않는다.

## README 사례 선정

현재 네 사례의 내용과 순서를 유지한다. 이번 출처 조사와 문서 보완은 새로운 제품 상태/데이터 경계를 해결한 구현 근거가 아니므로 기존 사례보다 기술 판단을 더 강하게 입증하지 못한다. 실제 코드 발췌, 여섯 항목 순서와 기능 화면을 보존한다.

## 남은 문제와 인계

실제 서비스 artifact와 공개 upstream commit 사이의 재현 가능한 대응이 없으면 버전 대응까지 완료로 단정하지 않는다. DES-08 전체, 앱 안의 접근 가능한 디자인 출처 및 모든 resolved release 라이브러리 조건은 별도 점검이다. PR74의 원래 두 번 위치 검증 동의는 미소비이며 사용자 직접 잠금 해제 확인을 기다린다.

2026-11-02 확인에서 공식 공모전 안내와 빈 양식8개의 원문 hash가 이전 확인과 같았다. 개발 자동화 종료 시각을 연장하지 않는다. 로컬 검증 뒤 GitHub 최신 CI/Codex/병합은 별도로 확인하며 실제 기기 미실행을 통과로 쓰지 않는다. 출처 고지 검토의 완료와 DES-08 전체의 미완료를 구분해 이 계획은 active에 유지한다.
