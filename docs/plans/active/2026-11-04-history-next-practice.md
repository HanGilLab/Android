# 선택한 과거 종료 기록에서 다음 연습 준비

- 상태: 진행 중. 실제 화면 검증과 최신 통합 head의 병합 조건은 미충족이다.
- 목표와 계약: 선택한 과거 종료 원본의 같은 목표/코스에서 과제를 직접 골라 준비만 저장한다. 기존 최신 경로는 latest-only이고 연습은 자동 시작하지 않는다.
- 저장 검증: 같은 transaction의 쓰기 전후에 실제 rowId/원시 자료형/전체 source, 미종료 행, 카탈로그/과제, P+UX와 취소를 재검사하고 실패하면 기존 자료를 보존한다.
- 진입과 복원: 표시 세대/RESUMED/단회 행동과 메모리 token을 묶으며, 원본 소실이나 오래된 token을 ID 또는 최신 기록으로 대체하지 않는다.
- 회귀 조건: 과거 선택/취소/명시 저장, source 변경/삭제/동일 ID 변경, 미종료/카탈로그/권한 변동과 rollback, 오래된 close/save/ACK 거부를 확인한다.
- 실제 화면: 기본 라이트와 1.3배 확대 다크의 선택/잠금/도달, production 내비게이션과 재생성은 아직 미실행이며 제어 Room 계측과 구분한다.
- 자동 검증: 이전 head의 JDK17 전체 verify/계측 APK와 CI/Codex는 통과했다. main 통합본은 새 검증과 최신 head 검토가 필요하다.
- 측정: 없던 선택 원본 경로를 연결하는 기능이므로 동일 동작의 전후 성능 비교는 N/A다. 속도나 사용자 성과를 주장하지 않는다.
- README: 네 사례와 짧은 실제 코드 여섯 발췌/이미지를 보존하고 기능 표 한 행과 실제로 이동한 source 앵커만 맞춘다.
- 완료 경계: 관련 실제 UI와 최신 필수 검사/리뷰 전에는 병합하지 않는다. 실제 도로 구간 연결과 APP-07 전체 완료를 대신하지 않는다.
