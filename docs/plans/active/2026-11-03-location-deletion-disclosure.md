# 종료 기록 삭제의 위치 표본/수집 상태 고지

- 목표: APP-08의 삭제 확인에 실제로 함께 지워지는 위치 표본과 수집 상태를 명시한다.
- 범위: 기존 영구 삭제/복구 불가 경고를 보존하며 문자열만 고친다. 저장소, schema와 source/nonce/P/UX 경계는 바꾸지 않는다.
- 검증: 기존 ComponentCatalogActivity와 UUID 소유 Room 합성 자료로 문구, 취소/잠금 보존, 확인한 대상만 cascade 삭제와 Resources 복원을 확인한다. 실제 SDK/위치/권한 요청은 없다.
- 수동 조건: 기본 글꼴1.0/라이트와 글꼴1.3/다크의 실제 화면, 스크롤과 버튼 도달을 확인한다. 과거 baseline의 문구 누락 RED와 현재 head의 GREEN을 구분한다.
- 현재 상태: 최신 main을 일반 통합했으며 현재 head의 실제 UI GREEN은 아직 미실행이다. 과거 실행을 소급 성공으로 쓰지 않는다.
- 완료: JDK17 전체 검사와 최신 PR CI/Codex, 위 실제 UI 조건을 충족한 뒤 정책대로 병합한다. 결과는 열린 PR #83에서만 추적한다.
- 측정 제외: 삭제 범주 고지의 의미 정확성 수정이며 앱 성능/사용 흐름 속도를 바꾸지 않는다. 저장 행 수나 RED/GREEN을 성능 수치로 쓰지 않는다.
- README: 기존 네 사례보다 강한 새 문제 해결 근거가 없어 사례/핵심 코드/화면을 유지한다.
