# 상세 펼침 처리의 최신 허용 조건과 선택 소유권

- 상태: 제어된 native 재현과 변경 전 계측 준비
- 요구사항: P와 UX 동시 확인, 상태 수신/처리 경계의 오래된 상세 조작 차단
- 기준 커밋: ad0c1d7acb9ba79e323ef1f2329c11b4f0be364a (제품eac86f6과 동일)

## 문제와 범위

PR47 후 자체 검토에서 ParkedDisclosure가 local expanded만 갱신하며, 부모 HistoryRoute의 canRead 재조합 전에 옛 버튼 콜백을 실행하면 최신 SDK 값/선택 소유권을 다시 확인하지 않는 경계를 확인했다. Compose의 자식 재조합이 부모 gate를 다시 실행한다고 보장하지 않는다. 실제 SDK에서 이 수신 순서를 강제했다고 주장하지 않으며 실제 제품 Route/Disclosure와 명시적인 제어 입력으로 native RED를 먼저 확인한다.

확정된 처리 경계에 동적 gate를 연결하고 현재 reader/query/source/표시 세대를 확인한다. 새 DB/권한/자료 쓰기/삭제/위치/내비는 추가하지 않는다. 종료 문서 PR48은 draft로 전환해 보류했고, 과거 head의 CI/리뷰 성공을 이 경계의 해결로 대체하지 않는다. 수정 PR이 main에 반영된 뒤 종료 기록을 갱신한다.

## 완료 조건

- [ ] 제품 수정 전 제어된 실제 Route/Disclosure native 검사에서 오래된 P 표시로 D 상태의 상세 펼침이 발생함을 RED로 재현한다. 실제 SDK 검증/성능 근거와 구분한다.
- [ ] 동적 처리 gate가 최신 P/UX와 현재 선택/read 소유권을 확인한다. denied 요청은 확장 의도로 남지 않고 접기는 항상 가능하다. content 반영 직전에도 확인한다.
- [ ] 단위/제어된 native GREEN, JDK17 전체 verify와 실제 Pleos 기본/확대 다크 P-D-P 및 관련 기존 흐름을 확인한다.
- [ ] 변경 전후 고정 P/UX의 실제 상세 펼침 처리 비용을 같은 조건/계측으로 수집한다. 정확성 검증을 성능 개선으로 쓰지 않는다.
- [ ] 모든 원래 자료/권한/설정과 기존 측정 근거를 보존하고 최신 PR CI/리뷰/수동/정책 충족 후 main/브랜치/보류 종료 문서를 정리한다.

## 변경 전후 측정

이번 목표는 정확성 경계 수정이며 빠른 펼침을 가정하지 않는다. 추가 live/context 판정의 실제 처리 비용을 관찰한다. 현재 이력 진입의 30표본(eac86f6)은 펼침 비용이 아니므로 이 수정의 성능 개선 근거로 대체하지 않는다.

- 지표: 실제 제품 History 화면의 과제별 기록 버튼 클릭 호출 직전부터 상세 scope가 생성되고 실제 viewport에서 표시/Compose idle이 확인될 때까지 monotonic ms. 클릭 전달/idle/semantics 계측 overhead를 포함하며 앱 내부 프레임/GPU/SDK/사용자 속도는 아니다.
- 기준: 제품ad0c1d7, 계측 SHA는 실제 빌드 후 기록한다. 제품 수정은 RED와 실제 기준값 수집 이후에만 시작한다.
- 조건/입력: 같은 기존 Android14/API34 Pleos/JDK17 debug, 실제 SDK P+UX, 원래 준비1/종료9/관찰15/메모0/최신 종료 source와 원문 카탈로그/글꼴1.0/라이트. 새 프로세스/Activity 뒤5회 워밍업/30회. 매회 새로 이력을 열어 접힘으로 초기화하고 동일 source를 확인한다. 무거운 Gradle/AVD는 순차 실행하고 캐시를 지우지 않는다.
- 타이밍 밖: 원본/환경/SDK/source 대조, 이력 진입, 마지막 버튼 시각까지 사전 스크롤해 scope가 펼쳐질 공간 확보, JSON/닫기/원문/최종 복원. 같은 start/endpoint 함수를 전후에 그대로 사용한다.
- 실패/제외: source/환경/원본 불일치, P/UX 미허용,20초 endpoint 미확인, 예외/복원 불일치는 실패로 중단한다. 느린 표본 제거/0 대체/완료 파일 덮어쓰기 없이 원값/순서/성공/실패/누락/미실행/제외를 별도 보존한다.
- 비교: 원값30개, 중앙값/Q1/Q3/IQR/min/max, 절대 차이/상대 변화, 순차 실행/발열/캐시/계측 편차를 남긴다. 기준0은 상대율을 계산하지 않고 인과적 성능 개선/안정 비용을 확정하지 않는다.

## 남은 문제와 인계

PR48은 기존62dd2d0의 CI4개/Codex 완료를 과거 근거로 보존한 draft다. 제품 수정 후 최신 main을 정상 통합해 두 계획의 종료를 갱신하고 최신 head 검사/리뷰를 다시 받는다. PR47 원래 리뷰를 임의 변경하거나 해당 리뷰가 이 결함을 지적한 것으로 기록하지 않는다. 기존 최초 확대 외부 DDS 전환 누락과 옛 history_finished timeout 미확정은 이 source 경합과 별도로 유지한다.
