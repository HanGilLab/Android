# 저장된 위치 수집 중단 원인 복습 연결

- 상태: 진행 중. 실제 화면 검증과 최신 통합 head의 병합 조건은 미충족이다.
- 목표: 선택한 종료 기록에 저장된 중단 원인 12종과 원인 미기록을 구분해 표시한다.
- 범위: 기존 실행 카드에 원인 한 행만 연결하며 SDK 수집, 권한 요청, schema와 실제 경로는 바꾸지 않는다.
- 저장 의미: OPEN과 알 수 없는 끝 시각, 과거 중단, 저장 상한을 보존하고 enum보다 구체적인 고장 원인을 추정하지 않는다.
- 안전 조건: 전체 source/token, P+UX와 RESUMED, 오래된 행동 거부 및 명시적 재진입을 유지한다.
- 회귀 조건: UUID 소유 Room의 합성 자료로 원인/선택/잠금, 자료와 sequence/FK 보존, SDK와 플랫폼 동작 비호출을 확인한다.
- 실제 화면: 기본 라이트와 1.3배 확대 다크의 가시성, 버튼 도달, 잠금 복귀와 리소스 복원은 아직 미실행이다.
- 자동 검증: 이전 head의 JDK17 전체 verify/계측 APK와 CI/Codex는 통과했다. main 통합본은 새 검증과 최신 head 검토가 필요하다.
- 측정: 새 저장 필드 표시의 의미 정확성 연결이므로 성능 비교는 N/A다. 속도나 사용자 성과를 주장하지 않는다.
- 완료 경계: 관련 실제 UI와 최신 필수 검사/리뷰 전에는 병합하지 않는다. README 네 사례와 실제 이미지는 보존하며 APP-06 전체 완료로 확대하지 않는다.
