# 준비한 코스의 고정 시연 지점 지도 연결

- 상태: 진행 중
- 요구사항: MAP-02의 코스별 지도 미리보기 연결 부분. 최신 체크리스트의 실제 도로 구간/출발/도착 검토, MAP-01 전체와 MAP-02 전체는 별도 미완료다.
- 기준 커밋: fe23ab92580f7cd205c32a0aa45bab7dc8d72467

## 목표와 범위

현재 저장된 준비의 코스 ID/버전을 검증한 뒤 해당 코스의 고정 시연 지점을 실제 지도에 표시한다. 현재 지도는 준비와 무관한 시청 주변만 보여 코스 선택이 지도에 연결되지 않는다. 기존 지도 렌더/실패/재시도/생명주기와 P+UX 계약을 재사용한다. 새 위치/내비 API나 권한, DB 마이그레이션은 필요하지 않아 과거 원래 head 리뷰와 선행 체크 전체 미체크가 이 독립 연결을 막지 않는다.

두 허구 예시 코스에 현재 미리보기만 선택적으로 붙인다. 별도 preview ID/version과 고정 출처를 두고 기존 코스/브리핑 버전과 준비/과거 세션 스냅샷은 바꾸지 않는다. 좌표는 공개 OSM 랜드마크 면의 경계 중심으로 정의한 표시점이며 출입구/도로점/차량 목적지/다각형 내부점 보장이 아니다. 폴리라인, 실제 이동 경로, 거리/시간, 실시간 위치와 길안내는 제공하지 않는다.

## 구현 단계

1. 최신 체크리스트/진행 계획/lease/실제 PR/CI와 공식 안내/좌표 원자료를 읽는다.
2. 순수 domain의 출처가 고정된 미리보기 모델과 현재 카탈로그 데이터를 추가하고 준비 읽기/화면 토큰을 연결한다.
3. 실제 지도에 번호 지점을 렌더하고 준비/오류/잠금 UI 및 실제 native 검증을 추가한다.
4. 실제 검증이 끝난 화면만 README에 반영하고 기존4사례와 비교한다. 최신 PR 검증과 병합 후 main/브랜치를 정리한다.

## 변경 전후 측정

이전 main에는 저장된 코스의 지점을 표시하는 실행 경로가 없다. 성능 병목의 최적화가 아니라 미완료 제품 연결이며 전후 성능 개선율을 주장하지 않는다. 기능 가시성/출처/상태/보존과 실제 렌더를 확인하고 검사 수/행 수를 성능으로 바꾸지 않는다. 추후 실제 병목을 관찰하면 변경 전에 측정 계약대로 기준값부터 실행한다.

- 병목과 관찰 근거, 개선 가설: 코스 선택이 지도에 연결되지 않은 구현 부재. 성능 가설 없음.
- 지표와 단위, 비교 방향: 성능 비교 적용 제외. 선택에 맞는 지점/지도/출처/잠금/실패/복원을 확인.
- 기준/비교: fe23ab9, 비교는 실제 제품 소스/PR head로 고정.
- 조건: 기존 전용 Pleos debug 앱, 고정 OSM 표시점, 실제 P+UX 허용, 기본1.0/라이트 및 확대1.3/다크. SDK 사용자 위치는 읽거나 사용하지 않음.
- 표본/순서/제외: 기능 시나리오와 실제 저장 데이터 대조이며 성능 표본 미수집. 실패/미실행/미지원과 성공은 분리.
- 원값/재현: 실제 데이터/기기/화면 원문과 처리 이력은 ignored 비공개 체크포인트에 보존. 공개에는 정제 결과만 기록.

## 공개 좌표 근거

OSM way6개의 frozen geometry와 공식 버전 API ID/name/version을 확인했다. 기준2026-10-30T11:56:20Z의 bounding-box center가 공개 표시점이며 실제 도로 선형/주행 검토 근거가 아니다. 데이터는 ODbL1.0, © OpenStreetMap contributors와 원본 URL을 별도 출처 안내로 유지한다.

## README 사례 선정과 비교

기존1/2/4번의 주제와 순서는 보존한다. 기존3번의 View/시도 식별 사례를 수신된 선택과 조회 세대, reader 및 View 콜백의 경합까지 강화했다. 기존3번은 재생성된 View 구분에 집중했지만 새 근거는 코루틴 전달 취소만으로 닫히지 않는 수신→해석 경계와 상태 원자성까지 실제 재현으로 좁혔다. 따라서 같은 비동기 지도 사례 안에서 원인 규명, 취소 대안의 한계와 본인의 구현 판단을 더 설득력 있게 보여 준다. 새 기능/코드량/검사 수를 선정 근거로 쓰지 않았다. 나머지 사례는 교체 근거가 없어 유지하며 최종 개수는4개다. README11개 Kotlin 발췌는 공통 들여쓰기를 제외한 현재 소스와 링크 구간이 일치한다. 공개 README에는 회귀 목록/집계/미측정 성과표를 넣지 않는다.

## 남은 문제와 인계

구현과 최종 검증/리뷰는 미완료다. 실제 도로 구간, 출발/도착 검토, 길안내와 MAP-01/MAP-02 전체, 독립 UX 제한 조합 및 과거 원래 head 리뷰는 별도 미완료로 유지한다. 다른 저장소/포트폴리오 문서는 열거나 변경하지 않는다.
