# 목표·코스 선택과 출발 전 준비

- 상태: 진행 중
- 요구사항: 기획서의 목표·코스 저장(R1), 출발 전 브리핑·오늘의 과제(R2)

## 목표와 범위

목표 → 시연용 코스 → 브리핑·과제 하나 선택 → 저장 → 재실행 복원 흐름을 구현한다.
차량이 P이고 UX 제한 해제를 확인한 경우에만 상세 화면과 저장을 허용한다.
실제 경로 안내·주행 기록·복습은 후속 작업이며, 코스는 도로 검토를 받지 않은 시연 자료다.
사용자 요청에 따라 기존·신규 최상위 타입을 이름별 파일로 분리하고 개발 지침에 반영한다.

## 완료 조건

- [x] 목표 2종과 시연용 코스 2종에서 준비 내용을 선택하고 홈에서 확인한다.
- [x] 코스·브리핑 버전과 과제 하나를 Room에 원자적으로 저장하고 재실행 시 복원한다.
- [x] 취소·저장 실패는 기존 준비 내용을 유지하고, 변경된 코스 버전은 재선택을 요청한다.
- [x] D·상태 미확인 시 상세 내용과 입력이 잠기며 대기 중 저장도 취소한다.
- [ ] 자동 검증, Pleos 실행 확인, PR CI와 Codex 리뷰 결과를 기록한다.

## 구현 단계

1. domain 계약과 Room 저장소, 시연 카탈로그를 추가한다.
2. 독립 course feature와 앱 화면 연결, 홈 요약을 구현한다.
3. 저장·복원·버전·잠금 예외를 검증하고 PR을 제출한다.

## 남은 문제와 인계

실제 도로 코스 검토, 내비게이션 연동과 주행 기록은 이번 범위에 포함하지 않는다.
