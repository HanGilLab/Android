# README 핵심 코드 확장과 회귀 근거 제외

- 상태: 진행 중
- 요구사항: 코드 맥락을 더 보여 주고 회귀 검증 근거를 빼며 실제 전후 성능은 측정 후 넣으라는 사용자 지시

## 목표와 범위

README의 기존 네 사례와 지정 순서, 개요/사진/스택/아키텍처는 유지한다.
기존 실제 구현의 중요한 처리 흐름을 더 충분히 발췌하고 코드 접기를 제거한다.
공통 검증 기준, 회귀 검증 근거, 테스트 집계/CI 소개는 README에서 제거한다. 실제 개발 검증은 계획/PR/CI에서 계속 수행한다.
AGENTS와 측정 안내, 자동화/메모의 작성 규칙을 같은 기준으로 정정한다. 실제 성능 전후 값과 개선폭/측정 조건은 자료를 확보했을 때 결과에 넣고 빈 성과표는 만들지 않는다.
앱 실행 코드/DB/권한/이미지와 별도 포트폴리오/이력서는 변경하지 않는다.

## 구현 단계

1. 현재 코드와 관련 명세를 확인한다.
2. 실제 개선이면 변경 전 기준값을 먼저 측정한 뒤 가장 작은 검증 가능한 변경을 구현한다.
3. 같은 조건의 변경 후 측정과 회귀 검증을 비교하고 리뷰 결과를 반영한다.

## 변경 전후 측정

README와 작성 지침만 정정하므로 앱 성능 측정 적용 대상이 아니다.
성능 자료가 없으며 개선율이나 빈 성과표를 README에 만들지 않는다.

## 남은 문제와 인계

실제 전후 성능 자료는 없으며 확보했을 때 결과에 추가한다. README의 기존 네 사례는 더 강한 새 사례가 없어 내용과 순서를 유지한다.
회귀 검증 실행은 유지하되 README에 근거를 다시 넣지 않는다. 새로운 앱 동작과 권한 변경이 없어 새 Pleos 실기는 미실행이다.
완료 조건이 충족되면 상태를 완료로 바꾸고 이 파일을 `completed/`로 이동한다.
