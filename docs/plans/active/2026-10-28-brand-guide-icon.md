# 브랜드 방향과 길잡이 로고·런처 아이콘

- 상태: 진행 중
- 요구사항: [공모전 체크리스트 DES-01·DES-02](https://app.notion.com/p/40586a7a8f8a800092c1caea490e8a09)

## 목표와 범위

기본 Android 아이콘으로 보이던 앱을 민트·크림과 둥근 길잡이 마크로 식별할 수 있게 한다.
브랜드 원칙·원본 벡터·워드마크 조합·adaptive/monochrome 런처 아이콘을 준비하고 주차 상태의 홈·코스 헤더에 적용한다.
화면 전체 재디자인·장면 일러스트·공통 디자인 토큰 완성은 DES-03~07 후속 범위로 둔다.
위치 권한 동의 대기 중인 PR #10은 변경하거나 대신 병합하지 않는다.

## 완료 조건

- [x] 색·형태·문구·주행 중 사용 제한과 출처를 브랜드 원칙에 기록한다.
- [x] 같은 길잡이 마크가 원본 SVG·앱 벡터·런처의 일반/원형/단색 아이콘으로 식별된다.
- [x] P+UX 확인 때 홈·코스의 로고/워드마크가 보이고 D·미확인에는 장식 마크가 제거된다.
- [x] 실제 Pleos 런처·앱과 밝은/어두운 배경·마스크에서 가림·잘림·식별을 확인한다.
- [ ] 전체 검증·관련 UI 시나리오·최신 PR CI와 Codex 리뷰를 확인한다.

## 구현 단계

1. 기존 민트 팔레트를 유지하며 작은 길잡이 얼굴과 길 모티프의 원본 벡터를 만든다.
2. 동일 마크를 공유하는 Compose 브랜드 조합과 adaptive launcher 리소스를 연결한다.
3. 실제 주차/주행 화면과 아이콘을 검증하고 관찰 근거·후속 범위를 기록한다.

## 남은 문제와 인계

DES-04 토큰과 dark palette 전역 정리는 이번 작업으로 완료 처리하지 않는다.
로고는 앱 식별자이며 운전 능력 인증·안전 보장을 뜻하지 않는다.
외부 이미지·폰트 파일을 추가하지 않고 프로젝트 소스의 벡터와 시스템 글꼴을 사용한다.
미확인·끊김의 조건식은 기존 `allowsPracticeInteraction`을 유지했다. 이번 직접 수동 전환은 P→D→P이며 모든 오류 상태를 새로 수동 주입한 것으로 기록하지 않는다.
위치 권한 동의 대기 PR #10은 별도 브랜치에 보존했다. 이 브랜치에는 해당 권한을 추가하지 않았다.
