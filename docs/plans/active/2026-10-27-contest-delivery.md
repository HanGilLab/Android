- 서명 원본, 연락처, 로컬 경로, 기기 식별자, 인증정보를 노션, 저장소, 공개 산출물에 기록하지 않는다.
- 사용자 발송 확인 전에는 제출 완료로 표시하지 않고 발송 사실과 접수 확인을 구분한다.
- 자동 작업은 2026-11-10 종료 시점까지만 운영한다. 이후 미완료 작업을 자동 연장하지 않는다.
- 로컬 자동 작업에는 컴퓨터와 Codex 앱 실행이 필요하다.
- 2026-10-29 정합 확인: ENV-09의 JDK 준비와 SUB-11의 원본 공개 접근은 실제 검증, 관련 PR 병합으로 완료돼 각각의 계획을 `completed/`로 정리했다. 필수 완료 수는 기존 19/54를 유지하며 새 항목을 완료로 늘리지 않는다. 초기 설정 PR #1의 최신 head에는 Codex 완료 근거가 없어 초기 계획은 미완료로 보존한다.
