# 공개 도로 미리보기와 선택

- 문제: 코스 지도에는 지점만 있고 실제 도로 형상을 골라 확인할 수 없다.
- 범위: 버전과 노드 좌표를 대조한 공개 OSM 도로 두 개를 생활권 코스에 표시하고, 같은 화면의 목록 선택과 해제로 해당 선을 강조한다.
- 완료 기준: 원자료 순서와 출처 보존, 실제 LineString과 선택 강조, 기존 점 선택 회귀, 주차/UX/STOP/코스 교체 뒤 이전 요청 거부, 두 테마 가독성.
- 제외: 구간의 세션 저장, 위치 표본 매칭, 통행 적합성, 내비 안내 경로 일치. 새 권한과 Vehicle/Fused/Navi SDK 호출은 사용하지 않는다.

## 구현과 검증

1. 별도 도로 스냅샷과 카탈로그 자료, 배포용 출처 고지를 연결한다. way와 각 노드 버전을 따로 고정하며 노드 정렬, 보간과 합치기를 하지 않는다.
2. 점과 도로를 구분한 단일 선택 상태로 기존 소유권 가드를 공유한다. 도로 source와 LineLayer는 점 source와 분리한다.
3. 기존 JVM/Room 경계 검증과 차량/위치 상태를 제어한 실제 Compose/MapLibre 시나리오를 재사용한다. JDK17 전체 검사와 최신 CI/Codex 리뷰 후 병합한다.
4. 결과와 실패, 미실행은 해당 PR에서 추적한다. README 네 사례는 더 강한 별도 근거가 없으면 유지한다.

새 기능의 연결이며 관찰한 성능 병목이나 변경 전 대응 기능이 없다. 전후 성능 측정이나 속도 개선을 주장하지 않는다.

## 종료 연습에 복습 구간 연결

- 문제: 도로 선택이 지도에서 사라지면 어느 연습의 복습 대상이었는지 다시 확인할 수 없다.
- 범위: 종료 원본에 사용자가 고른 공개 도로 하나의 원형을 명시 저장하고, 같은 복습 화면에서 다시 읽거나 해제한다. 실제 이동과 GPS 매칭, 구간별 메모와 다음 과제 자동 선택은 포함하지 않는다.
- 저장: 종료 원본, 현재 선택 버전과 도로/노드 출처를 대조하고 주차/UX/취소를 거래 전후 확인한다. 삭제 확인에도 새 연결 자료를 포함한다. 저장된 도로는 현재 카탈로그로 바꾸지 않는다.
- 화면: 마침 복습과 지난 연습이 공유하는 펼침 영역에서 선택, 저장, 재조회와 명시 해제를 제공한다. 전체 연습 메모와 실제 SDK 표본은 별도로 유지한다.
- 검증: 기존 Room/마이그레이션과 소유권 가드를 재사용하고 변경된 저장/롤백/삭제 경계에 필요한 회귀만 추가한다. 격리 Room, 제어된 차량/UX와 실제 Compose/MapLibre로 저장 후 재진입/해제와 두 테마를 확인한다. 원래 DB/권한/설정을 보존하고 새 부팅, Vehicle/Fused/Navi 호출과 JDI는 사용하지 않는다.

이는 미완료 기능 연결이며 변경 전 동등한 저장 흐름이나 관찰한 성능 병목이 없다. 속도나 성능 개선율을 주장하지 않는다. 결과와 실패는 열린 작업 PR에서 추적한다.

## 다음 과제 선택에서 복습 구간 참고

- 문제: 종료 연습에 저장한 복습 도로를 다음 과제 선택 화면에서 볼 수 없어 이전 화면을 다시 열어야 한다.
- 범위: 같은 종료 원본의 저장 도로명, 사용자 선택 출처와 지도를 현재 과제 선택 화면에서 읽기 전용으로 펼쳐 본다. 기존 조회, 지도와 소유권 가드를 재사용하며 새 DB 계약과 ViewModel을 추가하지 않는다.
- 경계: 기본 닫힘과 미사용 slot은 조회하지 않는다. 과제, 원본, 주차/UX와 수명주기가 달라지면 이전 참고 화면을 폐기한다. 없음, 조회 실패와 재시도를 구분하고 참고 조회만으로 과제 선택, 준비 저장과 원본 기록을 바꾸지 않는다. 준비 저장은 기존 코스/과제 필드만 저장하며 도로가 승계됐다고 표시하지 않는다.
- 검증: 기존 격리 Room과 실제 Compose/MapLibre 완주 시나리오에 읽기 전용 표시, 과제 변경과 잠금 뒤 이전 소유권 폐기, 취소/준비 저장 뒤 원본 보존을 추가한다. 기본 라이트와 확대 다크를 확인하며 기존 앱, DB/WAL, 설정과 권한 플래그를 보존한다. 새 부팅, Vehicle/Fused/Navi 요청과 JDI는 사용하지 않는다.

미완료 제품 맥락 연결이며 관찰한 실행 성능 병목이나 변경 전 동등한 화면 흐름이 없다. 성능 전후 수치와 속도 개선은 주장하지 않고 결과와 실패는 열린 PR에서만 추적한다. 기존 네 README 사례의 기술적 영향과 재현 근거보다 강한 새 근거가 없으면 사례는 보존한다.

## 선택한 복습 도로의 사용자 메모

- 문제: 복습할 도로를 저장해도 그 도로에서 기억할 점을 남길 수 없어 연습 전체 메모와 구분되지 않는다.
- 범위: 저장된 도로에 원문 메모를 인라인 작성, 수정, 비우고 재조회한다. 기존 메모 입력 UI와 조회/쓰기 소유권을 재사용하며 다음 과제 참고 화면은 읽기만 한다. 실제 이동 매칭과 운전 평가를 뜻하지 않는다.
- 저장: schema 9에 메모 TEXT 열 하나를 추가한다. 빈 문자열은 미작성이며 나머지는 기존 280 코드포인트/텍스트 정책을 따른다. 원문과 버전을 전체 CAS에 포함하고 같은 도로의 메모만 바뀌면 헤더만 갱신한다. 은퇴한 도로도 기존 메모는 편집할 수 있다.
- 손실 방지: 메모가 있는 도로의 교체와 해제는 기본 거부한다. 현재 원형과 목표에 고정된 확인에서만 메모 삭제를 명시하며 취소와 오래된 확인은 쓰지 않는다. 전체 연습 메모와 다른 기록은 유지한다. 전체 세션 삭제는 기존 확인 원형과 cascade에 메모를 포함한다.
- 검증: 기존 도메인/Room/마이그레이션 및 VM 회귀를 확장하고 실제 Compose/MapLibre의 원문 입력, 응답 유실 뒤 재조회, 재진입, 취소와 잠금 뒤 이전 확인 거부를 기본 라이트와 확대 다크에서 확인한다. 격리 Room만 사용하며 기존 앱, DB/WAL, 권한과 설정을 보존한다. 새 부팅, Vehicle/Fused/Navi 호출과 JDI는 하지 않는다.

미완료 기능 연결이며 변경 전 동등한 구간 메모 처리나 관찰한 실행 성능 병목이 없다. 성능 수치나 운전자 성과를 주장하지 않는다. 실패와 최종 검증은 해당 열린 PR에서 추적하고 더 강한 채용 근거가 없으면 README 네 사례를 보존한다.

## 저장 표본과 선택 복습 도로 함께 보기

- 문제: 저장 위치 표본과 같은 연습에 저장한 사용자 선택 도로가 서로 다른 지도에 있어 한 화면에서 비교할 수 없다.
- 범위: 위치 기록에서 지도를 명시적으로 펼칠 때 기존 도로 reader를 읽기 전용으로 재사용해 표본 한 점과 저장된 공개 도로 원형을 같은 지도에 표시한다. 같은 전체 종료 원본을 확인하며 새 DB, SDK 요청, 자동 매칭과 연결선을 추가하지 않는다.
- 경계: 조회 중/없음/실패를 구분한다. 표본 선택, 도로 원형/버전, 주차/UX와 수명주기 변경은 이전 native view와 입력을 폐기한다. 표본과 도로의 외부 타일 요청 범위를 열기 전에 고지한다. 정확도와 SDK 시각 미확정, 사용자 선택 출처와 실제 이동 미확인을 유지한다.
- 검증: 기존 controlled 위치 기록/격리 Room과 실제 MapLibre 시나리오를 확장해 표본과 도로의 별도 source/geometry, 원형 변경/해제, 조회 실패/재시도, 표본 전환과 잠금 뒤 이전 화면 제거를 기본 라이트와 확대 다크에서 확인한다. 기존 앱/DB/WAL/설정/권한을 복구하며 새 부팅, 권한, SDK 관찰과 JDI는 사용하지 않는다.

## 복습 도로를 다음 연습 목표로 가져오기

- 문제: 다음 과제 화면의 복습 도로는 참고만 가능해 저장된 준비와 다음 세션을 열면 사라진다.
- 범위: 같은 종료 원본의 저장 복습 도로를 사용자가 명시적으로 고르면 도로/노드 원형과 원래 선택의 식별자를 비재귀 목표 값으로 복사한다. 메모는 복사하지 않으며 새 주행/복습 결과나 내비 경로로 등록하지 않는다. 준비와 시작/종료 세션이 각각 독립 값을 보존한다.
- 저장: nullable 목표 JSON 열을 준비와 세션, 전체 원본을 복사한 기록 세 곳에 각각 추가하고 엄격한 canonical codec으로 타입/원형을 검증한다. 도로/원본/버전/seed와 주차/UX/취소를 저장 거래 전후 대조한다. 일반 편집은 전체 기존 준비 CAS를 확인하고 같은 목표/코스/버전의 과제 변경에만 목표 도로를 유지한다. 목표/코스 변경 시 해제를 저장 전에 표시하고 취소는 원본을 유지한다.
- 화면: 기존 다음 과제 화면의 명시 선택과 연결 해제, 준비/활성/종료 화면의 짧은 목표 요약을 제공한다. 이전 기록이 변경되거나 조회가 실패하면 과거 선택/저장 요청을 폐기한다. 원래 연습 삭제와 목표 사본 삭제 범위를 구분한다.
- 검증: 기존 도메인/Room/마이그레이션과 다음 과제/준비 편집 검증을 확장한다. 명시 저장과 재조회, 같은 코스 과제 변경 보존/다른 코스 해제, 저장 실패/취소/경합, 새 세션 시작/종료와 원래 세션 삭제 뒤 목표 원형 보존을 실제 격리 Room/Compose의 라이트와 확대 다크에서 확인한다. 기존 앱/DB/WAL/권한/설정은 복구하며 새 부팅, Vehicle/Fused/Navi 요청과 JDI는 하지 않는다.
