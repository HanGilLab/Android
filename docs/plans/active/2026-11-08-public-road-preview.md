# 공개 도로 미리보기와 선택

- 문제: 코스 지도에는 지점만 있고 실제 도로 형상을 골라 확인할 수 없다.
- 범위: 버전과 노드 좌표를 대조한 공개 OSM 도로 두 개를 생활권 코스에 표시하고, 같은 화면의 목록 선택과 해제로 해당 선을 강조한다.
- 완료 기준: 원자료 순서와 출처 보존, 실제 LineString과 선택 강조, 기존 점 선택 회귀, 주차/UX/STOP/코스 교체 뒤 이전 요청 거부, 두 테마 가독성.
- 제외: 구간의 세션 저장, 위치 표본 매칭, 통행 적합성, 내비 안내 경로 일치. 새 권한과 Vehicle/Fused/Navi SDK 호출은 사용하지 않는다.

## 구현과 검증

1. 별도 도로 스냅샷과 카탈로그 자료, 배포용 출처 고지를 연결한다. way와 각 노드 버전을 따로 고정하며 노드 정렬, 보간과 합치기를 하지 않는다.
2. 점과 도로를 구분한 단일 선택 상태로 기존 소유권 가드를 공유한다. 도로 source와 LineLayer는 점 source와 분리한다.
3. 기존 JVM/Room 경계 검증과 차량/위치 상태를 제어한 실제 Compose/MapLibre 시나리오를 재사용한다. JDK17 전체 검사와 최신 CI/Codex 리뷰 후 병합한다.
4. 결과와 실패, 미실행은 해당 PR에서 추적한다. README 네 사례는 더 강한 별도 근거가 없으면 유지한다.

새 기능의 연결이며 관찰한 성능 병목이나 변경 전 대응 기능이 없다. 전후 성능 측정이나 속도 개선을 주장하지 않는다.

## 종료 연습에 복습 구간 연결

- 문제: 도로 선택이 지도에서 사라지면 어느 연습의 복습 대상이었는지 다시 확인할 수 없다.
- 범위: 종료 원본에 사용자가 고른 공개 도로 하나의 원형을 명시 저장하고, 같은 복습 화면에서 다시 읽거나 해제한다. 실제 이동과 GPS 매칭, 구간별 메모와 다음 과제 자동 선택은 포함하지 않는다.
- 저장: 종료 원본, 현재 선택 버전과 도로/노드 출처를 대조하고 주차/UX/취소를 거래 전후 확인한다. 삭제 확인에도 새 연결 자료를 포함한다. 저장된 도로는 현재 카탈로그로 바꾸지 않는다.
- 화면: 마침 복습과 지난 연습이 공유하는 펼침 영역에서 선택, 저장, 재조회와 명시 해제를 제공한다. 전체 연습 메모와 실제 SDK 표본은 별도로 유지한다.
- 검증: 기존 Room/마이그레이션과 소유권 가드를 재사용하고 변경된 저장/롤백/삭제 경계에 필요한 회귀만 추가한다. 격리 Room, 제어된 차량/UX와 실제 Compose/MapLibre로 저장 후 재진입/해제와 두 테마를 확인한다. 원래 DB/권한/설정을 보존하고 새 부팅, Vehicle/Fused/Navi 호출과 JDI는 사용하지 않는다.

이는 미완료 기능 연결이며 변경 전 동등한 저장 흐름이나 관찰한 성능 병목이 없다. 속도나 성능 개선율을 주장하지 않는다. 결과와 실패는 열린 작업 PR에서 추적한다.

## 다음 과제 선택에서 복습 구간 참고

- 문제: 종료 연습에 저장한 복습 도로를 다음 과제 선택 화면에서 볼 수 없어 이전 화면을 다시 열어야 한다.
- 범위: 같은 종료 원본의 저장 도로명, 사용자 선택 출처와 지도를 현재 과제 선택 화면에서 읽기 전용으로 펼쳐 본다. 기존 조회, 지도와 소유권 가드를 재사용하며 새 DB 계약과 ViewModel을 추가하지 않는다.
- 경계: 기본 닫힘과 미사용 slot은 조회하지 않는다. 과제, 원본, 주차/UX와 수명주기가 달라지면 이전 참고 화면을 폐기한다. 없음, 조회 실패와 재시도를 구분하고 참고 조회만으로 과제 선택, 준비 저장과 원본 기록을 바꾸지 않는다. 준비 저장은 기존 코스/과제 필드만 저장하며 도로가 승계됐다고 표시하지 않는다.
- 검증: 기존 격리 Room과 실제 Compose/MapLibre 완주 시나리오에 읽기 전용 표시, 과제 변경과 잠금 뒤 이전 소유권 폐기, 취소/준비 저장 뒤 원본 보존을 추가한다. 기본 라이트와 확대 다크를 확인하며 기존 앱, DB/WAL, 설정과 권한 플래그를 보존한다. 새 부팅, Vehicle/Fused/Navi 요청과 JDI는 사용하지 않는다.

미완료 제품 맥락 연결이며 관찰한 실행 성능 병목이나 변경 전 동등한 화면 흐름이 없다. 성능 전후 수치와 속도 개선은 주장하지 않고 결과와 실패는 열린 PR에서만 추적한다. 기존 네 README 사례의 기술적 영향과 재현 근거보다 강한 새 근거가 없으면 사례는 보존한다.
