# 공개 도로 미리보기와 선택

- 문제: 코스 지도에는 지점만 있고 실제 도로 형상을 골라 확인할 수 없다.
- 범위: 버전과 노드 좌표를 대조한 공개 OSM 도로 두 개를 생활권 코스에 표시하고, 같은 화면의 목록 선택과 해제로 해당 선을 강조한다.
- 완료 기준: 원자료 순서와 출처 보존, 실제 LineString과 선택 강조, 기존 점 선택 회귀, 주차/UX/STOP/코스 교체 뒤 이전 요청 거부, 두 테마 가독성.
- 제외: 구간의 세션 저장, 위치 표본 매칭, 통행 적합성, 내비 안내 경로 일치. 새 권한과 Vehicle/Fused/Navi SDK 호출은 사용하지 않는다.

## 구현과 검증

1. 별도 도로 스냅샷과 카탈로그 자료, 배포용 출처 고지를 연결한다. way와 각 노드 버전을 따로 고정하며 노드 정렬, 보간과 합치기를 하지 않는다.
2. 점과 도로를 구분한 단일 선택 상태로 기존 소유권 가드를 공유한다. 도로 source와 LineLayer는 점 source와 분리한다.
3. 기존 JVM/Room 경계 검증과 차량/위치 상태를 제어한 실제 Compose/MapLibre 시나리오를 재사용한다. JDK17 전체 검사와 최신 CI/Codex 리뷰 후 병합한다.
4. 결과와 실패, 미실행은 해당 PR에서 추적한다. README 네 사례는 더 강한 별도 근거가 없으면 유지한다.

새 기능의 연결이며 관찰한 성능 병목이나 변경 전 대응 기능이 없다. 전후 성능 측정이나 속도 개선을 주장하지 않는다.
