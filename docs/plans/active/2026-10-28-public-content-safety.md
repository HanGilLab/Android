# 공개 저장소 개인정보 보호

- 상태: 검증 대기, 공개 전환 차단
- 요구사항: 비공개 작업 주소, 개인정보, 로컬 환경을 공개하지 않고 저장소를 공개한다.

## 목표와 범위

현재 문서에서 비공개 작업 주소를 제거하고 로컬 DB, 서명, 진단 기록의 실수 커밋을 막는다.
일반 공개 SDK 의존성과 재현 안내를 사용자별 설치 위치, 기기, 권한, 원문 검증 기록과 구분한다.
작업용 원문과 기존 변경은 비공개 로컬 파일에 보존한다.

## 완료 조건

- [x] 현재 추적 문서의 비공개 기획 URL을 제거한다.
- [x] 로컬 데이터, 서명 파일의 추적을 방지하고 제한된 공개 콘텐츠 검사를 추가한다.
- [ ] 현재 파일, 과거 커밋, 모든 브랜치와 GitHub PR 참조의 비공개 주소, 작성자 개인정보를 정리한다.
- [ ] Actions 로그와 산출물 내부를 확인하고 남은 공개 자료를 검토한다.
- [ ] 서버의 과거 참조와 캐시까지 제거됐는지 확인한 뒤 실제 공개 접근을 검증한다.
- [ ] 최신 커밋의 자동 검사, PR 리뷰를 확인한다.

## 검증 결과

현재 파일과 과거 이력에서 실제 자격정보, 개인키는 발견되지 않았지만, 과거 커밋의 비공개 기획 주소와 작성자 개인 메일이 남아 있다.
GitHub의 과거 PR diff에서도 해당 주소가 발견됐다. 일부 과거 PR 본문의 주소는 제거했다.
Actions 로그에는 관련 패턴이 발견되지 않았으나 산출물 내부 검사는 아직 미완료다.
이는 제한된 패턴 검사이며 모든 비밀이 없다는 보장은 아니다.

## 남은 문제와 인계

최신 문서만 수정해도 과거 커밋, PR 참조, 캐시가 자동 삭제되지 않는다.
보호 규칙 우회나 미병합 변경 삭제 없이 이력 정리와 서버 잔여 참조 제거를 준비하고, 해결 전에는 비공개를 유지한다.
공개 전환, 이력 정리 완료로 표시하지 않는다.

- [GitHub 민감정보 제거 안내](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)

- 자동 검증: 추적 파일 패턴 검사와 synthetic 11개 검사를 통과했다. symlink 대상 내용을 읽지 않고 읽기 실패는 원문 진단 없이 실패 처리한다. 전체 공식 검사 4단계와 단위96개(실패/오류/건너뜀0), debug/unsigned release가 통과했다. 최초 Spotless 입력 직렬화 실패는 별도 보존했으며 설정/캐시 삭제 없이 독립 검사, 전체 재검증이 통과했다. 근본 원인은 미확정이다. PR 최신 검사는 별도로 추적한다.
