# 작업 이름

- 상태: 진행 중
- 요구사항: 원본 명세 또는 이슈 링크

## 목표와 범위

사용자가 얻게 될 동작과 이번 작업에서 바꿀 경계를 적는다.

## 완료 조건

- [ ] 관찰 가능한 성공 조건
- [ ] 예외 상황의 기대 동작
- [ ] 필요한 자동 검증과 실행 증거

## 구현 단계

1. 현재 코드와 관련 명세를 확인한다.
2. 가장 작은 검증 가능한 변경을 구현한다.
3. 검증과 리뷰 결과를 반영한다.

## 검증 결과

| 명령 또는 시나리오 | 결과 | 근거 |
|---|---|---|
| `./scripts/verify.sh` | 미실행 | |

## 남은 문제와 인계

실패한 검사, 확인하지 못한 환경, 다음 실행자가 필요한 정보를 적는다.
완료 조건이 충족되면 상태를 완료로 바꾸고 이 파일을 `completed/`로 이동한다.
