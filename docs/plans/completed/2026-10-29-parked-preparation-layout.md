# 주차 준비의 코스 선택과 브리핑 배치 개선

- 상태: 완료
- 요구사항: 공모전 DES-06의 코스 선택과 브리핑 우선 개선 (비공개 작업 명세)

## 목표와 범위

이미 구현된 준비 흐름의 코스 선택과 브리핑을 홈과 같은 민트/크림, 둥근 카드와 길잡이 디자인으로 정리한다. 정보 위계를 줄이고 넓은 화면에서는 설명과 선택을 두 열로, 글자 크기에 비해 폭이 부족하면 한 열로 표시한다. 준비 단계의 공통 헤더와 스크롤 초기화는 함께 점검한다. 카탈로그, 저장/권한 로직과 지도/내비 기능은 변경하지 않는다. DES-06 전체와 MAP-01의 기존 최종 리뷰 대기는 별도 미완료로 유지한다.

## 완료 조건

- [x] 실제 변경 전후 화면에서 시연 출처, 코스 구간, 선택 항목과 다음/저장 행동을 읽기 쉽게 구분한다.
- [x] 기본/확대 글꼴과 다크 모드에서 두 열/한 열 배치, 터치와 스크롤을 검증한다. 실제 P/UX 허용과 D 잠금/복귀에서 상세 내용과 장식을 확인한다.
- [x] 기존 선택/단계 이동/작성 취소와 저장 데이터 보존을 확인하고 JDK17 전체 검사, UI 계측과 최신 PR CI/Codex 리뷰를 통과한다.

## 구현 단계

1. 현재 준비 화면과 기존 브랜드/공통 컴포넌트, 실제 변경 전 화면을 확인한다.
2. 코스와 브리핑의 배치만 작은 범위로 바꾸고 기존 상태/콜백/태그/출처 안내를 유지한다.
3. 무거운 빌드와 Pleos 검증을 순차 실행한다. 실제 전면 화면과 캡처를 함께 보고 검증된 대응 이미지만 포트폴리오에서 교체한다.
