# 주차 중 연습 세션 시작·종료와 저장

- 상태: 완료
- 요구사항: [공모전 체크리스트 APP-03](PRIVATE_PLANNING_REFERENCE)

## 목표와 범위

준비한 목표·시연 코스·과제를 기준으로 사용자가 주차 중 연습을 시작하고, 주차 후 종료 시각을 저장한다.
진행 중 세션과 최근 종료 기록은 앱·DB 재실행 후 복원한다. 준비 내용·코스 버전과 표시명을 시작 당시 스냅샷으로 보관한다.
이번 단계의 기록은 사용자의 버튼 조작 시각이다. 위치·차량 이벤트·실제 경로·운전 능력 평가를 기록했다고 표현하지 않는다.
P0 수동 오류 조합과 위치 입력 검증은 별도 미완료로 유지한다. PR #10 권한 동의와 PR #11 리뷰를 대신 승인하거나 병합하지 않는다.

- [x] 시작 당시 선택·버전·표시명·시연 상태를 보존하고 활성 세션을 하나로 제한한다.

## 구현 단계

1. domain 모델·저장 계약과 Room 스키마·마이그레이션·트랜잭션을 추가한다.
2. 홈에 별도 세션 상태·ViewModel·주차 화면을 연결한다. 기존 준비·지도 동작은 유지한다.
3. 저장 복원·중복·오류·잠금의 자동 검사와 실제 AVD 시나리오를 검증하고 근거를 기록한다.

## 남은 문제와 인계

APP-04의 위치·차량 이벤트, APP-05의 내비 전환 후 수집, APP-06~08의 복습·다음 연습·전체 이력/삭제는 별도다.
종료 시각이 시작보다 앞서면 성공·0초로 보정하지 않는다. 오류를 표시하고 기존 세션을 유지한다.
사용자 DB·기존 AVD·미병합 브랜치·위치 검증용 APK 백업은 삭제하지 않는다.
실제 AVD DB가 v2가 된 뒤 v1만 지원하는 이전 PR #10 APK로 되돌리면 downgrade 오류가 발생한다.
위치 검증 재개 시 이 마이그레이션을 포함한 호환 후보를 재빌드하고, DB 삭제·destructive migration으로 우회하지 않는다.
실제 수동 입력은 P→D→P와 시작·종료 조작이다. 저장소 오류·독립 UX 조합을 실제 플랫폼에서 모두 주입했다고 기록하지 않는다.
완료 계획 이동 이후 문서 커밋의 최신 CI·Codex 리뷰는 PR에서 다시 확인한 뒤 병합한다.
