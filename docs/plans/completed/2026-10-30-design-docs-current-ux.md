# 현재 주차 UX와 디자인 기준 문서 정합

- 상태: 완료
- 요구사항: 최신 사용자 가독성 기준, PR #32의 구현과 DES-06 후속 문서 정합

## 목표와 범위

직전 UI 변경 뒤 남은 과거 색, 글꼴, 모서리와 공통 컴포넌트 적용 설명을 현재 소스에 맞춘다.
공통 기본 치수와 주차 전용 배치의 실제 치수를 구분해 후속 작업에서 작은 글자나 좁은 여백을 되살리지 않게 한다.
토스는 구성과 정보 위계의 참고이며 한길의 민트와 크림을 유지한다. 앱 소스, 화면, 저장 자료와 권한은 변경하지 않는다.

- [x] 토큰 문서의 색 쌍, Typography와 Shapes가 현재 소스와 일치한다.
- [x] Practice 기본 배치와 Parked 변형, 실제 적용 화면과 안전 조건을 구분한다.

- [x] 최신 PR CI와 Codex 리뷰, 미해결 지적을 확인한다. 문서만 변경하므로 새 실기는 미실행으로 구분한다.

1. 최신 체크리스트, 진행 계획, AGENTS, Git과 PR #8/#10의 실제 리뷰 상태를 읽는다.

## README 사례 비교

이번 문서 정정은 실제 사용자 가독성 효과나 새로운 상태/데이터 경계의 해결 수치를 확보한 작업이 아니다.
기존 네 사례의 주행 상태 경합, 트랜잭션, 비동기 View 콜백, SQLite 물리 자료형 검증보다 채용 관점에서 강한 구현 근거가 없어 내용과 순서를 보존한다.
차량 관찰 기록 실행기는 저장 기반의 가능한 독립 후속 단계로 검토했으나 이번에는 구현하지 않는다. 제품 수명주기와 누락 표시, 실제 SDK 수집 검증이 필요하며 선행 완료로 추정하지 않는다.
