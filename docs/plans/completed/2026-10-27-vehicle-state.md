# Pleos 차량 상태 연동과 주행 제한

- 상태: 완료
- 요구사항: 차량 SDK 연결, 실제 이벤트 수신, 주차·UX 상태에 따른 상세 조작 제한

## 목표와 범위

Vehicle SDK의 읽기 API로 연결 상태와 방향지시등·브레이크 상태를 수신한다.
AAOS의 주차·UX 상태를 확인하고 미확인·권한 거부·연결 해제 시 잠금을 유지한다.
개발용 상태 표시는 debug 빌드에서 제공한다. 내비·기록 저장·제품 화면은 후속 작업이다.

## 완료 조건

- [x] 연결 가능·미지원·권한 거부·끊김 상태를 구분한다.
- [x] Pleos Virtual Console의 방향지시등·브레이크 변경이 실제 SDK 콜백으로 반영된다.
- [x] 주차 상태와 UX 제한 해제를 모두 확인한 경우에만 상세 조작을 허용한다.
- [x] 상태 미확인·수신 실패·연결 해제 시 기존 값으로 잠금을 해제하지 않는다.
- [x] 콜백 등록·해제와 재연결 시 이전 콜백·값이 남지 않는다.
- [x] 자동 검증과 에뮬레이터 실행, PR CI·Codex 리뷰 결과를 확인한다.

## 구현 단계

1. 공식 SDK·권한·플랫폼 API와 실행 환경의 지원 여부를 확인한다.
2. domain 상태 모델, 차량·주행 제한 어댑터와 수명주기를 구현한다.
3. 개발용 표시와 예외·상태 전이 테스트를 추가한다.
4. 전체 검증·에뮬레이터 시나리오를 실행하고 PR 리뷰를 반영한다.
