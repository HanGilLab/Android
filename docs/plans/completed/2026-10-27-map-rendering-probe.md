# Pleos 주차 화면 지도 렌더링 검증

- 상태: 완료
- 요구사항: 공모전 체크리스트 MAP-01 (비공개 작업 명세)

## 목표와 범위

주차 상태와 UX 제한 해제를 모두 확인했을 때 실제 온라인 지도를 열어 Pleos에서 MapLibre Native + OpenFreeMap 표시가 가능한지 검증한다.
고정 시연 지역을 현재 위치, 선택한 코스처럼 표현하지 않으며 위치 수집, 코스 좌표, 자체 길안내는 후속 작업으로 둔다.
지도는 독립 feature 모듈에 격리하고 app에서 화면 이동을 조립한다.
주행, 연결 끊김, 상태 미확인에는 지도 상세 화면을 제거하고 잠금 안내를 표시한다.

## 완료 조건

- [x] 주차 화면에서 고정 시연 지역의 실제 지도, 한글 도로 표기, 출처를 확인한다.
- [x] 로딩, 오류, 재시도를 구분하고 네트워크 실패를 지도 준비 완료로 표시하지 않는다.
- [x] 진입, 이탈, Activity 재생성에 MapView 수명주기를 연결하고 실제 동작을 확인한다.
- [x] P+UX가 함께 확인된 경우에만 지도를 표시하며 D, 미확인 전환 시 상세 조작을 제거한다.
- [x] 관련 자동 검증, 전체 검증과 구현, 검증 커밋의 최신 PR CI와 Codex 리뷰를 확인한다.

## 구현 단계

1. 공식 artifact, renderer, 온라인 타일 사용 조건을 확인하고 명시적인 OpenGL 후보를 선택한다.
2. feature:map과 app/home 진입점을 추가하고 모듈 정책, 의존성을 갱신한다.
3. 실제 Pleos 지도 표시, 잠금, 재생성, 네트워크 실패를 확인하고 관찰한 결과를 기록한다.
4. 위치 입력 검증이 남아 있는 MAP-01 전체 항목은 미체크로 유지한다.

## 남은 문제와 인계

위치 권한, FusedLocation 입력은 후속 검증이다. 지도 표시만으로 MAP-01의 전체 완료를 선언하지 않는다.
네트워크 오류, 같은 프로세스 재시도 복구까지 실제 장치에서 확인했다. 초기 프록시 복원 문제는 성공으로 소급하지 않고 최종 재시도 검증과 구분한다.
실제 장치 캡처, 원본 로그, 네트워크 설정 백업은 ignored 로컬 검증 자료에 보존하며 공개 문서에는 경로, 기기 식별자를 기록하지 않는다.
ENV-06의 UX 독립 조합, 권한 거부, 미지원, 연결 단절 수동 재현은 별도 미완료로 유지한다.
PR #8은 사용자 지시로 최종 문서 리뷰 진행 중 예외 병합했으며, 뒤늦은 지적은 계속 확인한다.
