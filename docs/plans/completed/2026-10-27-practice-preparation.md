# 목표·코스 선택과 출발 전 준비

- 상태: 완료
- 요구사항: 기획서의 목표·코스 저장(R1), 출발 전 브리핑·오늘의 과제(R2)

## 목표와 범위

목표 → 시연용 코스 → 브리핑·과제 하나 선택 → 저장 → 재실행 복원 흐름을 구현한다.
차량이 P이고 UX 제한 해제를 확인한 경우에만 상세 화면과 저장을 허용한다.
실제 경로 안내·주행 기록·복습은 후속 작업이며, 코스는 도로 검토를 받지 않은 시연 자료다.
사용자 요청에 따라 기존·신규 최상위 타입을 이름별 파일로 분리하고 개발 지침에 반영한다.

## 리뷰 보완

저장 대기 중 시스템 뒤로가기로 화면을 떠날 때 저장을 즉시 취소하고, 완료 이벤트의 중복 화면 닫기를 차단했다.

## 남은 문제와 인계

실제 도로 코스 검토, 내비게이션 연동과 주행 기록은 후속 작업이다.
AVD 시스템 서비스 중단은 실행 환경을 복구한 뒤 재검증했다.
