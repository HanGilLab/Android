# 주차 화면용 길잡이 장면 일러스트

- 상태: 완료 (코드 검증·리뷰 완료, 완료 기록 커밋도 최신 검사 후 병합)
- 요구사항: 공모전 체크리스트 DES-03 (비공개 작업 명세)

## 목표와 범위

기존 자체 제작 길잡이의 민트·크림·잉크와 둥근 비율을 유지해 준비·복습·마무리 장면 에셋을 만든다.
SVG 원본과 대응 Android VectorDrawable을 함께 제공하고 출처·팔레트·용도를 문서화한다.
그림에 글자·실제 지도/차량 기록·점수·졸업/안전 인증을 넣지 않는다.
이번 범위는 장면 에셋 확보이며 제품 화면 적용(DES-06), 복습·다음 과제 구현, 전체 라이선스 점검(DES-08)은 별도다.
화면에 적용할 때 P와 UX 허용을 모두 확인한 주차 화면에서만 장식으로 사용한다.

## 완료 조건

- [x] 원본/리소스의 기하·색·배치가 일치하고 Android에서 실제 inflate/render할 수 있다.
- [x] 라이트/다크 배경과 작은/큰 크기에서 잘림·식별성을 시각 확인한다.
- [x] 출처·외부 소스 없음·라이선스/사용 경계와 파일 대응을 기록한다.
- [x] JDK17 전체 검사·관련 리소스 검증과 최신 PR CI·Codex 리뷰를 마친다.

## 구현 단계

1. 기존 브랜드 벡터와 토큰을 읽고 같은 길잡이 비율로 소품과 장면을 구성한다.
2. SVG와 Android 벡터의 대응을 검증하고 실제 Android 렌더링을 확인한다.
3. 자동 검사·시각 피드백·PR 검토 후 노션 DES-03에 실제 결과만 반영한다.

## 남은 문제와 인계

기존 화면에 이미지를 적용하거나 미구현 복습/마무리 기능을 완료로 표시하지 않는다.
플랫폼/SDK·위치 권한·주차 검증의 미완료 항목을 그림 제작 완료로 대신하지 않는다.
기존 AVD·앱 데이터·사용자 변경을 보존한다.
마무리 찻잔의 장식 김 선은 작은 다크 미리보기에서 약해지지만 컵과 장면 식별은 유지된다.
세부 선을 읽게 하거나 필수 상태 전달에 사용하지 않는다.
실제 Android의 작은 다크 미리보기는 래스터 경계가 조금 거칠지만 장면 구조·비율·인지성은 유지됐다.
SVG/Android 시각 검토와 읽기 전용 코드 검토에서 구체적 결함은 발견하지 못했다.
CI의 Node 런타임/runner 이미지 전환 안내는 성공 검사와 구분했으며 이번 에셋 변경의 실패로 기록하지 않았다.
