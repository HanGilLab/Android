# 주차 홈의 정보 위계와 가로 배치 개선

- 상태: 완료
- 요구사항: 공모전 DES-06의 홈 우선 디자인 개선 (비공개 작업 명세)

## 목표와 범위

사용자가 요청한 디자인 개선 중 이미 구현된 주차 홈만 작은 단위로 개선한다. 기존 민트/크림 토큰과 준비 일러스트, 둥근 카드와 버튼을 사용해 다음 행동과 준비 내용을 먼저 읽고 최근 기록을 구분할 수 있게 한다. 미완성 복습/완료 화면, 코스와 브리핑 디자인, 새 기능과 저장 로직은 이번 범위에서 바꾸지 않는다. DES-06 전체는 APP-08과 나머지 화면 검증까지 별도 미완료로 유지한다.

## 완료 조건

- [x] 실제 개선 전후 화면을 비교하고 다음 행동, 준비 요약과 최근 기록의 정보 위계를 확인한다.
- [x] 실제 P/UX 허용에서만 장식을 보이고 주행/미확인/오류 잠금과 기존 행동, 데이터 출처를 유지한다. 가로 배치와 큰 글꼴에서 읽기와 터치가 가능하다.
- [x] JDK17 전체 검사, UI 계측과 필요한 Pleos 시나리오, 최신 PR CI와 Codex 리뷰를 확인한다.

## 구현 단계

1. 기존 브랜드/컴포넌트와 홈의 실제 개선 전 화면을 확인한다.
2. 준비된 홈의 배치와 정보 위계만 바꾸고 현재 태그와 안전 재검증 경로를 유지한다.
3. 빌드와 실기를 순차 실행해 전후 비교, 글자 크기와 실제 잠금, 데이터 보존을 검증한다.

## 구현 결과

홈 헤더를 묶고 현재 행동과 최근 기록을 별도 카드로 나눴다. 화면 폭이 글자 크기에 비해 충분하면 현재 행동과 준비 내용을 두 열로 배치하며, 그렇지 않으면 한 열에서 스크롤한다. 준비 요약과 오늘 과제는 같은 열 안에서 쌓아 확대 글꼴에서도 다시 좁은 두 열로 돌아가지 않는다.

민트 강조 카드와 기존 준비 일러스트를 사용하며 장식은 준비 관련 단계와 충분한 공간에서만 보인다. 주행 잠금에서는 상세 카드와 장식이 모두 사라지고, P 복귀 후 기존 준비가 복원된다. 저장 로직, 권한, 시연 코스와 SDK 데이터의 구분은 바꾸지 않았다. Virtual Console의 실제 DDS 연결과 기어 전환, 앱의 수신과 잠금/복원을 함께 확인했다.

## 남은 문제와 인계

DES-06 전체는 미완료다. 코스와 브리핑을 비롯한 나머지 화면 개선, 복습/완료 기능의 선행 조건과 최종 시나리오는 별도 작업이다. 이번 UI 변경은 실제 P/D 전환을 검증했으며 독립적인 UX 제한 조합 주입의 기존 환경 제약을 해소한 것으로 기록하지 않는다. 구현 커밋의 검사와 리뷰는 끝났으며, 종료 문서를 포함한 최신 PR 검사와 리뷰를 다시 확인한 뒤 병합한다.
