# 한길졸업 브랜드 원칙

초보 운전자가 연습을 준비하고, 주차 후 경험을 돌아보며 다음 연습으로 이어가도록 돕는 작은 길잡이다.
민트와 크림 색, 둥근 형태를 사용하며, 운전 능력을 채점하거나 졸업이나 안전을 인증하는 배지처럼 표현하지 않는다.

## 길잡이 마크와 워드마크

- 둥근 민트 몸, 크림 얼굴, 작은 미소와 굽은 길 모티프로 구성한다. 과장된 표정, 번쩍임, 운전 중 애니메이션은 사용하지 않는다.
- 앱 헤더는 마크와 ‘한길졸업’ 텍스트를 결합한다. 작은 런처 아이콘에는 글자를 넣지 않는다.
- 워드마크는 시스템 글꼴의 굵은 headlineSmall이다. 별도 폰트 파일을 배포하지 않는다.
- SVG 원본은 `design/brand/hangil-guide.svg`, 앱 벡터는 `core/designsystem`의 `ic_hangil_guide`다. 동일 path와 색으로 유지한다.
- launcher foreground는 앱과 같은 벡터를 참조한다. 단색 마크는 같은 윤곽과 얼굴과 길의 음각을 유지한다.

## 색과 형태

| 역할 | 색 | 사용 |
|---|---|---|
| Forest | `#126B59` | 앱 식별 배경, 기존 주요 행동색 |
| Ink | `#073D31` | 얼굴, 윤곽, 길 |
| Mint | `#A7DAC4` | 길잡이 몸 |
| Cream | `#FFF6E6` | 얼굴과 길의 중앙선 |
| Cheek | `#E9B69F` | 작은 장식 포인트만 사용 |

상태, 오류, 잠금은 기존 문구와 컴포넌트로 설명한다. 캐릭터 색만으로 정상, 실패, 완료를 구분하지 않는다.
브랜드 색 리소스는 그림에 적용한다. 화면의 라이트와 다크 색 역할, 간격, 모서리, 타이포는
DES-04에서 정리한 [디자인 토큰](tokens.md)을 따른다.

## 주차와 주행, 접근성

- P와 UX 허용을 모두 확인한 홈, 코스에만 확대된 로고와 워드마크를 표시한다.
- 주행, 미확인, 끊김, 권한 거부의 상세 잠금 화면은 기존 간단한 제목과 안내를 유지한다.
- 런처, 시스템의 작은 앱 식별 아이콘은 플랫폼 정책을 따른다. 확대 장식이나 상세 조작 허용을 뜻하지 않는다.
- 마크는 추가 버튼이 아니다. 이미지 설명은 중복 낭독하지 않고 결합된 앱 이름을 제공한다.
- 문구는 다음 행동을 구체적으로 안내하고, 실수, 불안, 위반, 운전 능력을 단정하거나 꾸짖지 않는다.

## 런처, 출처와 후속 범위

108dp foreground 안 중앙 66dp 안전 영역에 핵심 그림을 둔다. Android 8+ adaptive icon과 Android 13+ monochrome 리소스를 제공한다.
원형, 둥근 사각형 마스크와 밝은/어두운 배경에서 식별을 확인한다. 작은 크기에서는 마크만 사용한다.
벡터는 프로젝트 소스로 직접 작성했다. 외부 이미지, 아이콘, 폰트 파일을 포함하지 않는다.
준비, 복습, 마무리 장면의 원본, Android 리소스와 출처는 [일러스트 안내](illustrations.md)에 기록한다.
전체 화면 적용(DES-06), 사용성 최종 점검(DES-07), 전체 에셋 라이선스 정리(DES-08)는 별도다.
