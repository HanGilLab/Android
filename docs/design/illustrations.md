# 주차 화면용 길잡이 일러스트

준비 카드, 펼친 복습 노트, 덮어 둔 마무리 노트의 세 벡터와 첫 준비용 생성형 그림이다.
기존 세 벡터는 민트 길잡이의 몸, 얼굴, 길 모양을 그대로 사용하고 크림 배경과 둥근 소품을 더했다.
그림의 노트와 카드는 장식이며 실제 과제 수, 기록, 운전 평가나 졸업이나 안전 인증을 뜻하지 않는다.

## 원본과 Android 리소스

| 장면 | 원본/제작 방법 | `core/designsystem` drawable |
|---|---|---|
| 준비 | `design/illustrations/hangil-prepare.svg` | `il_hangil_prepare` |
| 복습 | `design/illustrations/hangil-review.svg` | `il_hangil_review` |
| 마무리 | `design/illustrations/hangil-finish.svg` | `il_hangil_finish` |
| 첫 준비 | 기존 한길 길잡이를 참고한 생성형 PNG | `drawable-xxxhdpi/il_hangil_first_prepare.png` |

기존 세 SVG는 `360 × 240` viewBox, Android 벡터는 같은 viewport와 `360dp × 240dp` 기본 크기를 사용한다.
배경 바깥은 투명하며 가로세로 비율은 3:2다. 늘이거나 잘라 채우지 않고 내부 여백을 포함해 표시한다.
변경 시 두 표현의 path, 색, 불투명도, 선, 그룹 변환, 그리기 순서를 함께 갱신한다.

기존 세 벡터의 색은 [브랜드 원칙](brand.md)의 Forest, Ink, Mint, Cream, Cheek 다섯 색이다.
벡터의 Android 표현은 기존 `hangil_brand_*` 색 리소스를 참조한다. 별도 다크 전용 캐릭터나 상태색으로 바꾸지 않는다.
밝은 배경과 어두운 배경 모두에서 크림 판과 윤곽이 구분되는지 확인한다.

## 출처와 사용 경계

- 세 장면은 저장소의 자체 제작 `design/brand/hangil-guide.svg`를 확장해 직접 작성한 벡터다.
- 길잡이의 원본 7개 경로를 유지하고 노트, 카드, 찻잔 소품을 추가했다.
- 외부 이미지, 아이콘, 지도, 글꼴 파일 또는 외부 링크를 포함하지 않는다. 저장소의 [LICENSE](../../LICENSE)를 따른다.
- 첫 준비 PNG는 자체 길잡이의 민트/크림 팔레트를 기준으로 OpenAI 이미지 생성 도구로 제작했다. 1536×1024 투명 PNG이며 기존 벡터와 path/색의 수학적 동일성을 주장하지 않는다.
- 이 문서는 위 에셋의 출처 기록이다. 지도, 라이브러리, 전체 출품 자료의 사용 조건 점검(DES-08)은 별도다.

## 화면 적용 조건

홈의 첫 준비 그림은 기록이 확인된 빈 목록이고 준비도 비어 있을 때 기존 112dp 슬롯에서만 선택한다. 오류/로딩/미확인 상태를 빈 기록으로 대신하지 않는다. 기본/확대/다크의 실제 구성 검증과 전체 DES-06 완료는 별도다.
주차와 UX 제한 해제를 모두 확인한 화면에서만 확대 장식으로 사용한다.
주행, 연결 끊김, 미확인, 권한 거부의 잠금 화면에는 확대 장식을 배치하지 않는다.
실제 SDK 기록, 시연 데이터, 사용자 메모의 출처 안내를 그림으로 대신하지 않는다.

행동 버튼과 상태 문구는 그림 밖에서 명시한다. 인접 문구와 의미가 중복되는 장식은 접근성 설명을 중복 낭독하지 않는다.
144×96처럼 작은 크기는 보조 장식용이며, 세부 카드 선을 읽게 하거나 기능 버튼으로 사용하지 않는다.
마무리 그림이 있다고 복습, 다음 과제, 과정 종료 기능이 구현된 것으로 표시하지 않는다.

## 검증 방식

SVG와 Android 벡터의 기하, 색, 불투명도, 선, 그룹 변환 및 원본 길잡이 경로를 비교한다.
`SceneIllustrationRenderTest`는 Activity를 열지 않고 Android `VectorDrawable`을 실제로 로드해 그린다.
각 장면을 144×96, 720×480과 밝은/어두운 대표 페이지 배경에 렌더링하고 보이는 내용과 투명한 외곽 여백을 검사한다.
생성된 12개 이미지와 비교판은 비공개 앱 캐시에 저장하며 실제 시각 확인에 사용한다.
이 리소스 검증은 제품 화면 통합, 글자 확대, 주차 전환이나 실제 복습 동작의 검증을 대신하지 않는다.

생성형 PNG는 기존 SVG/VectorDrawable 경로 비교의 대상이 아니다. 같은 슬롯의 크기, 투명 합성, 기본/확대/다크와 상태별 선택은 HomeScreen 제어 렌더에서 확인하며 차량 SDK 실기로 대신 계산하지 않는다.
