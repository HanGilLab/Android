# 시작·종료 시각을 저장하는 연습 세션

APP-03은 주차와 UX 허용이 모두 확인된 홈에서 사용자가 연습의 시작·종료 버튼을 누른 시각을 기기에 저장한다.
이 시각은 차량이 실제로 출발·도착한 시각이나 실제 주행 여부의 증거가 아니다.
위치·차량 이벤트·주행 경로는 아직 수집하지 않으며, 내비 전환 중 수집·복습·전체 이력·삭제는 후속 항목이다.

## 저장과 복원

- 시작 당시의 목표·코스·과제 ID와 표시명, 코스·브리핑 버전, 시연/검토 상태를 스냅샷으로 보존한다.
- 활성 세션은 하나만 허용한다. 시작 버튼이 중복 호출되면 기존 활성 세션을 반환한다.
- 종료는 요청한 세션 ID에만 적용한다. 이미 종료된 세션을 다시 종료해도 새 활성 세션을 바꾸지 않는다.
- 시작 직전 저장된 준비 내용을 트랜잭션에서 다시 확인한다. 비어 있거나 변경·버전 불일치가 있으면 시작하지 않는다.
- 시작·종료 쓰기 전후에 실제 차량·UX 상태를 확인하고 허용되지 않으면 트랜잭션을 롤백한다.
- 진행 중 기록과 최근 종료 기록은 앱 재실행·DB 재개방 후 복원한다. 현재 준비를 변경해도 기존 스냅샷은 바뀌지 않는다.

시각은 기기 시계의 epoch milliseconds 원값을 저장하고 화면에서는 현재 기기 시간대로 표시한다.
시작보다 앞선 종료 시각은 오류로 남기며 0초나 정상 종료로 보정하지 않는다. 시간 기반 운전 점수·기간 판정을 제공하지 않는다.
최근 기록의 정렬은 DB 생성 순서를 사용해 기기 시계가 뒤로 바뀌어도 새 기록이 과거 기록 뒤에 숨지 않도록 한다.

읽기 실패는 빈 이력으로 바꾸지 않는다. 실패·재시도를 보여주고 기록을 확인하기 전 새 세션을 시작하지 않는다.
저장 오류도 성공으로 처리하지 않으며 기존 기록을 관찰해 복원한다. 중복·지연 응답은 저장소의 원래 결과를 표시한다.

## DB 호환성과 검증

Room v1→v2는 기존 준비 테이블을 유지하고 세션 테이블·인덱스를 추가한다. destructive migration을 사용하지 않는다.
v2로 갱신된 DB에 v1만 지원하는 과거 APK를 실행하면 downgrade 오류가 발생한다.
이전 위치 검증 PR을 재개할 때는 호환 마이그레이션이 포함된 후보를 다시 빌드하고 DB를 지우지 않는다.

자동 검사는 실제 v1 schema로 만든 DB의 마이그레이션·준비 보존, DB 재개방, 동시·중복 조작, 오래된 종료 대상,
시계 역행, 저장 중 잠금의 롤백, 저장소 오류 전파와 ViewModel의 실시간 잠금·재시도를 확인한다.
실제 Pleos 검증은 별도로 시작→화면 재생성→프로세스 재실행→종료·복원과 DDS의 P→D→P를 확인한다.
계측 테스트는 전용 AVD의 저장된 준비를 사용하며 기존 활성 세션을 임의로 종료하거나 데이터를 삭제하는 자동 초기화를 포함하지 않는다.
