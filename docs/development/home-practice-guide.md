# 홈의 다음 행동 안내

홈은 별도 “온보딩을 봤음” 플래그 대신 저장된 준비, 연습 기록을 읽어 다음 행동을 정한다.
주차와 UX 허용이 모두 확인된 경우에만 안내, 목표, 상세 행동을 보여주며 실제 입력 직전의 ViewModel/Repository 검증을 재사용한다.

| 확인한 상태 | 홈의 안내와 행동 |
|---|---|
| 준비 없음 | 목표, 코스, 오늘의 과제 준비 |
| 준비 내용 변경됨 | 코스, 과제 다시 선택 |
| 준비 완료, 이력 없음 또는 최근 종료 연습과 다른 선택 | 과제 확인 후 시작 시각 저장 |
| 활성 연습 있음 | 연습 당시 목표, 코스, 과제와 주차 후 마무리 |
| 종료 이력, 그 연습과 같은 유효한 준비 있음 | 최근 시작/종료 기록 확인, 다음 준비 또는 같은 코스로 새 연습 |
| 로딩 / 읽기 실패 | 확인 중 / 다시 불러오기. 새 연습으로 추정하지 않음 |
| 연결, 주차와 UX 미확인/제한 | 기존 잠금 화면, 안내, 상세 행동, 장식 숨김 |

활성 연습은 현재 준비보다 먼저 판단하고 그 세션의 스냅샷을 표시한다.
현재 준비가 없어졌거나 바뀌어도 시작할 때의 목표, 코스, 과제를 현재 준비로 덮어쓰지 않는다.
준비 행동은 안내 카드 한 곳에 두고 시작, 마무리의 중복 저장 방지 조건도 유지한다.
최근 종료 연습과 목표, 코스, 코스/브리핑 버전, 과제의 선택을 비교하므로 다른 준비를 저장하면 시작 안내로 넘어간다.
같은 선택을 다시 저장했는지는 별도 저장 시각/플래그로 추정하지 않으며, 이때도 기존 코스로 바로 새 연습을 시작할 수 있다.

`준비 → 주행 → 주차 후 복습 → 다음 연습`은 전체 흐름의 설명이다.
현재 저장하는 정보는 사용자가 누른 시작과 종료 버튼 시각이다.
복습 메모와 다음 과제 연결은 준비 중으로 표시하며, 실행되지 않는 복습/추천 버튼이나 운전 능력 평가를 제공하지 않는다.

## 검증 경계

- `HomeJourneyStepTest`: 로딩, 오류, 잠금, 활성 스냅샷 우선과 준비 없음/변경됨, 종료 이력의 안내 분기.
- `HomeJourneyFlowTest#freshInstallPreparationStartFinishAndRecreation`: 새로 설치한 분리 검증 패키지에서 빈 DB → 준비 저장 → 시작 → 마무리, Activity 재생성, 다음 준비 진입/미저장 복귀, 다른 코스 저장 후 시작 안내 복원.
- `HomeJourneyFlowTest#existingRecordsGuideAfterProcessRelaunch`: 기존 앱을 프로세스 종료 후 다시 실행해 저장 이력의 안내, 준비 진입/미저장 복귀, Activity 재생성 확인.
- `HomeJourneyFlowTest#actualDriveTransitionHidesGuideAndRestoresAfterPark`: 실제 DDS 콘솔 P→D→P에서 안내, 상세 행동 숨김/복원 확인.

첫 실행 검증은 기존 데이터를 지우지 않도록 동일 소스, DI, 실제 Room 저장소의 applicationId만 분리한 일회성 패키지를 사용한다.
정상 패키지, 소스의 applicationId와 APK를 복원하고, 기존 DB 전후 전체 행을 대조한다.
신규 패키지가 이미 있으면 덮어쓰거나 삭제하지 않는다. 이번 검증에서 새로 만든 패키지만 정리한다.
위치 권한은 이 안내에 필요하지 않다.

새 패키지 첫 실행, 기존 패키지 프로세스 재실행, Activity 재생성을 서로 구분해 기록한다.
계측 성공만으로 표시를 확정하지 않고 계측 중 전체 PNG에서 실제 중앙 앱과 글꼴 확대 시 잘림을 확인한다.
각 계측 전에 공식 LAUNCHER로 대상 앱을 열고 중앙 전면을 확인한다. 계측의 Activity 실행만으로 Pleos 내비에서 앱으로 전환됐다고 추정하지 않는다.
기대 노드를 기다릴 때 일시적인 UI 계층 부재는 미확인으로 처리하며 제한 시간 내 명시적인 노드가 나타나야 통과한다. [Compose 존재 조회 API](https://developer.android.com/reference/kotlin/androidx/compose/ui/test/SemanticsNodeInteractionCollection)
원문 DB, 장치 식별자, 개인 경로, 전체 플랫폼 dump는 공개 자료에 포함하지 않는다.
